# 🎵 SticKeys Music Website

Official website for **SticKeys** — a high-energy live mashup band blending Western hits with Eastern flavors, performing at corporate events, hotels, and large-scale shows across the region.

🌐 Live site: [stickeysmusic.com](https://stickeysmusic.com)

---

## Pages

| Page | Description |
|------|-------------|
| `/index.html` | Homepage with hero section and featured live performance |
| `/about.html` | Band story and background |
| `/discography.html` | Music and video content |
| `/services.html` | Event types and offerings |
| `/book.html` | Booking inquiry form |

---

## Features

- Fully responsive design (mobile + desktop)
- Embedded YouTube live performance video
- Booking functionality
- Clean navigation with mobile hamburger menu
- Deployed and live via GitHub Pages

---

## Built With

- HTML5, CSS3, JavaScript
- Hosted on GitHub Pages
